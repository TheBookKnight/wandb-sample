# Weight and Biases: Exercises

## Setup to run scripts
1. Install Python 3.13 or higher
2. Setup a virtual environment to protect your system from incompatible dependency issues via `python3 -m venv {YOUR_SUBDIRECTORY_NAME}` and `source <YOUR_SUBDIRECTORY_NAME>/bin/activate`
3. Install dependencies via `python -m pip install -r requirements.txt`
